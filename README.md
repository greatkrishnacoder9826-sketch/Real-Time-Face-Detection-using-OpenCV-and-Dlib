# Real-Time Face Detection using OpenCV and Dlib

## 📌 Project Overview

This project is a **real-time face detection system** built using **Python**, **OpenCV**, and **Dlib**.
It uses your webcam to capture live video and detects human faces in real time.

The detected faces are highlighted with a rectangle and numbered on the screen.

---

## 🚀 Features

* Real-time webcam face detection
* Detects multiple faces at the same time
* Displays face count on the screen
* Uses Dlib's frontal face detector
* Easy and beginner-friendly Python project

---

## 🧠 Working Principle

1. Webcam captures live video.
2. Frames are converted into grayscale.
3. Dlib detects frontal faces.
4. OpenCV draws rectangles around detected faces.
5. Face count is displayed on screen.
